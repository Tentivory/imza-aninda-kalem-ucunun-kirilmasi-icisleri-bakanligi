# imza-aninda-kalem-ucunun-kirilmasi-icisleri-bakanligi
Kalemin ucunun tam imza anında kırılmasını resmi iç güvenlik olayı, milli mürekkep egemenliği ihlali ve yetki protokolü sapması sayan; kapağı mühür, ucu müfettiş, 'biraz silkerim yazar' cümlesini olağanüstü hal bildirimi ilan eden Bakanlık. Gerçekten çalışır. Kalemler artık valiliktir.
